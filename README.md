# 全职高手

<img src="assets/app-icon.png" width="96" alt="全职高手图标">

全职高手是一款面向 BOSS 直聘的桌面求职助手，将招聘网站和 AI 辅助功能放在同一个窗口中，帮助你筛选职位、整理简历、生成沟通内容并跟进求职进度。

本仓库用于提供安装包、版本说明和自动更新服务。功能变化见 [更新日志](CHANGELOG.md)。

## 主要功能

- **职位筛选**：根据个人资料与求职偏好采集、筛选和评估职位，保存结果，减少重复筛选。
- **打招呼**：生成单个或批量职位的破冰内容，审核、编辑后确认发送，并展示发送结果。
- **沟通助手**：分析当前对话，生成回复或给出归档建议；支持筛选值得回复的会话、批量生成与审核发送。
- **简历管理**：导入个人资料、管理多份简历，分析简历之间的差异，辅助推荐适合发送的版本。
- **通勤与进度**：配置高德地图服务以测算通勤，查看职位状态和求职进度。

## 下载与安装

前往 [Releases 下载最新版本](https://github.com/tamaka365/job-pilot/releases/latest)。

目前支持 **macOS 14 及以上、Apple Silicon（M 系列芯片）**。暂不提供 Intel Mac 和 Windows 安装包。

1. 下载名称包含 `mac-arm64.dmg` 的安装包。
2. 打开 DMG，将 **全职高手** 拖到「应用程序」文件夹。
3. 从「应用程序」启动软件。

当前版本未使用 Apple Developer ID 签名或公证。首次打开可能被 macOS 拦截；确认安装包来自本仓库后，可在「系统设置 → 隐私与安全性」中按系统提示允许打开。

## 首次配置

### 1. 登录 BOSS 直聘

在软件内嵌的 BOSS 页面中登录你的账号。

### 2. 配置 Agent CLI

AI 功能需要本机已安装并完成登录的 Agent CLI。目前支持 Antigravity、Codex 和 WorkBuddy。

进入「设置 → Agent CLI」选择工具；支持模型与思考深度选择的工具，可进一步设置。点击「检测当前草稿」，检测通过后点击「保存 CLI 配置」。**检测不会代替保存。**

依赖未配置、尚未检测或不可用时，相关功能会提示你前往设置。

### 3. 填写个人资料

在「个人资料」填写真实技能、经历、求职方向和薪资等偏好，并保存。固定表单未涵盖的信息，例如工作形式、加班接受程度和沟通偏好，可写入备注补充。

需要简历推荐时，添加相应简历；有多份简历时，可以勾选至少两份分析差异。若要通过 BOSS 发送附件简历，还需提前将对应文件上传到 BOSS，附件文件名应与软件中记录的简历名称一致。

### 4. 配置通勤服务（按需）

使用通勤测算前，在设置中填写高德地图 **Web 服务 API Key**，检测通过后保存，并在个人资料中配置居住地址等相关信息。

## 日常使用

### 筛选职位与打招呼

进入「职位列表」的采集/筛选页面，设置目标数量后开始筛选；完成后查看职位结果。对感兴趣的职位使用单个打招呼，或勾选多个职位进行批量打招呼。

生成破冰内容后，先核对、按需编辑，再确认发送。批量操作会逐个发送，并展示结果。

### 分析对话与批量回复

进入「沟通助手」，选择会话并点击「分析当前对话」。根据分析结果审核回复、简历选项或归档理由。

点击「批量回复」时，软件会筛选值得回复的会话并生成内容。你可以查看最近的对话记录、取消勾选、修改文本和简历选择，确认后批量发送。

## 应用更新

安装版支持自动检查新版本，也可以在「设置 → 应用更新」点击「检查更新」，按更新窗口提示下载安装。

有未保存资料或正在执行的任务时，安装会暂缓；保存并等待任务结束后，可以继续更新。

## 数据与使用说明

个人资料、职位记录和设置保存在本机。进行 AI 分析时，相关资料、职位或对话上下文会通过你选择的 CLI 发送给其模型服务；通勤测算会调用高德接口。

生成内容供你审核和编辑，发送前请核对事实、措辞及附件简历。遇到登录失效、验证码或页面异常时，先在内嵌 BOSS 页面中处理，再重试操作。
